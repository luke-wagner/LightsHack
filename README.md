# LightsHack

![Pacman Example gif](docs/pacman.gif)

## About

This branch is an adaptation of the main project to run on a ESP32-WROOM-32 board. The point of this project is to use a ESP32 as a dedicated controller for the lights. Buttons or joysticks controllers will later be hooked up to the board for user input and game control.

## Technologies Used

The project is using a ESP32 with MicroPython firmware installed. The project files in **device_files** are uploaded to the root of the ESP32's file system (this can be done with a tool like Thonny IDE).
